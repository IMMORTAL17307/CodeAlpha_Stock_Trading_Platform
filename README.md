# CodeAlpha_Stock_Trading_Platform
A Java application simulating a stock trading platform, built during the CodeAlpha Virtual Internship.

### 📝 Project Overview
The **Stock Trading Platform** is a Java-based simulation that mimics a real-world stock market. This project demonstrates core backend logic for handling financial transactions. Features include:
* Simulating the buying and selling of stocks
* Tracking portfolio balance and stock ownership
* Viewing simulated market prices

### 🛠️ Technologies Used
* Java
* Object-Oriented Programming (OOP) principles
* Data Structures for managing stock inventory and user portfolios
